Fluxo em 4 passos

  1. 1
    Instale a extensão

    Baixe o .vsix e instale no Cursor (Command Palette → Install from VSIX).

  2. 2
    Abra o Cursor com CDP

    Feche o Cursor (Cmd+Q) e abra de novo com debug port. Sem isso a extensão não enxerga o agent.

  3. 3
    Use a senha de acesso

    Cmd+Shift+P → CursorRemote: Open Setup Panel. O server sobe sozinho. Senha padrão: 81020002abc.

  4. 4
    Conecte o celular

    Abra connect.blocks.pw/app e entre com a senha. Sem ngrok — o Cloudflare Tunnel aponta pro seu Mac.

Instalar de verdade

1. Extensão

No Cursor: Cmd+Shift+P (Windows: Ctrl+Shift+P) → Extensions: Install from VSIX... → escolha o arquivo baixado. Recarregue se pedir.

cursor --install-extension ~/Downloads/cursor-remote-0.1.53.vsix

2. Cursor com CDP

# macOS (Fish)
open -a Cursor --args --remote-debugging-port=9222

# Windows (PowerShell)
& "$env:LOCALAPPDATA\Programs\cursor\Cursor.exe" --remote-debugging-port=9222

# Linux
cursor --remote-debugging-port=9222

Confira: http://localhost:9222/json deve devolver JSON.

3. Setup + celular

  • Sidebar CursorRemote → Server Running
  • No celular, abra o painel e entre com a senha 81020002abc
  • Troque a senha em Settings → cursorRemote.webappPassword se quiser

Cada pessoa controla o próprio Cursor. A extensão roda na máquina dela; não é o server de outra pessoa.
