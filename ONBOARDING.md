# CursorRemote — instalação (você e amigos)

Site: [https://connect.blocks.pw](https://connect.blocks.pw)

## Fluxo cloud (recomendado)

1. Instale o `.vsix` (baixe no site)
2. Cursor com CDP: `open -a Cursor --args --remote-debugging-port=9222`
3. Setup Panel → copie o pairing code (túnel cloud sobe sozinho)
4. No celular: [connect.blocks.pw/app](https://connect.blocks.pw/app) → cole o código

Funciona fora de casa. Sem ngrok.

## Admin (dono do hub)

[connect.blocks.pw/list-table](https://connect.blocks.pw/list-table) — lista agents online, kick, rotaciona código.
